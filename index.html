01

The Golden Workflow

  1. Add only what you are editing: Use /add file.js for files the LLM must edit.
  2. Add background as read-only: Use /read doc.md so the LLM has context without wasting tokens or editing by mistake.
  3. Ask concise instructions: "Add user avatar to navbar with fallback initials"
  4. Review git commits: Aider automatically commits each change with sensible commit messages.
  5. Undo if unhappy: Use /undo to cleanly roll back code and context.
02

Architect Mode Pattern

Combine a superior reasoning model with a fast editing model for complex refactoring:

aider --model o3-mini --editor-model claude-3-7-sonnet
  • Architect: Solves reasoning, designs architecture, writes execution plan.
  • Editor: Executes code replacement blocks accurately.
03

Automated Test-Driven Repair

Run tests or linters and let Aider automatically fix failures until everything passes:

aider --test-cmd "pytest tests/" --auto-test

Inside the chat, you can also run one-off test cycles with /test <command>.

04

Repository Map Optimization

Aider creates a tree-sitter map of your entire codebase to know where functions and symbols live.

aider --map-tokens 2048 --map-refresh auto
  • --map-tokens 0: Disables repo map (saves tokens on tiny projects).
  • --map-tokens 4096: Deep structural visibility on huge enterprise repos.
